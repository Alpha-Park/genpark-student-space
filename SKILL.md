# genpark-student-space

An open-source GenPark alternative to Acrobat Student Spaces.

Instead of a restrictive web app, this skill turns your agent into an interactive tutor. Feed it lecture slides (images/PDFs) or notes, and it generates quizzes, summarizes concepts, and mentors you via the CLI.
